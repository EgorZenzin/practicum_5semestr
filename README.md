# Лабораторная работа №4

# Описание работы

## Цель работы

Целью данной лабораторной работы является разработка автоматизированных API тестов для сайта Restful-Booker на языке Python с использованием библиотеки `pytest`. Тесты направлены на проверку основных функциональностей API, включая получение токена аутентификации и создание бронирования. 

## Структура проекта

├── .github/          # Папка для конфигураций GitHub Actions
├── src/              # Основная папка с исходным кодом
│   ├── api/          # API-клиенты для взаимодействия с Restful-Booker
│   │   ├── auth_api.py  # API для аутентификации и получения токена
│   │   ├── booking_api.py  # API для создания и управления бронированиями
│   │   └── schemas/      # JSON-схемы для валидации ответов
│   │       ├── init.py
│   │       ├── auth_schema.json
│   │       ├── booking_detail_schema.json
│   │       └── booking_schema.json
│   └── tests/         # Тестовые файлы
│       ├── test_create_booking.py  # Тесты для создания бронирования
│       └── test_get_token.py       # Тесты для получения токена
├── pytest.ini         # Конфигурация для pytest
├── requirements.txt    # Список зависимостей
└── README.md          # Описание проекта

## Запуск тестов

**Склонируйте репозиторий:**

https://github.com/EgorZenzin/practicum_5semestr/tree/4laba

**Установите зависимости:**

pip install -r requirements.txt

**Запустить все тесты можно с помощью команды:**
